# Only I Showed Up

A tiny Node/TypeScript program for the make.fun bounty "Worst Monday One-Liners". It writes one funny single-line joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 140 characters about the worst Monday.

Entry line:

> Monday 8 a.m.: my alarm, my laptop, and my motivation all agreed to call in sick — only I showed up.

Run it with: `node main.ts`
